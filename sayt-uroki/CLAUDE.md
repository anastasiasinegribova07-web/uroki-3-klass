# Проект: sayt-uroki

## Что это
Сайт-расписание с уроками 3 класса (русский, математика, чтение,
окружающий мир) на 20.11–12.12.2026: тема, краткий конспект,
материалы, ДЗ, отметка «урок проведён» и заметка.

## Для кого
Для учителя и студентов-практикантов, которые ведут уроки, пока
учитель на сессии или чемпионате. Открывают в основном с телефона.

## Что уже решили
- Весь сайт в одном файле `index.html`.
- Вид: светлый, строгий, тёплый, спокойные цвета; сначала телефон.
- Главный экран: расписание на день. Нажатие на урок открывает окно:
  тема, конспект, материалы, в конце ДЗ и две кнопки.
- Конспект даётся текстом (не ссылкой); в «Материалах» ссылки только на
  презентацию и рабочий лист. Столбец «Конспект (ссылка)» в таблице скрыт.
- Картинка в конспекте: отдельная строка `[картинка: imya-fajla.png]`
  в ячейке конспекта; сам файл лежит в папке `kartinki` рядом с
  `index.html` (имя латиницей, без пробелов). Нажатие открывает крупно.
  Новую картинку учитель загружает на GitHub в папку `kartinki`.
- Остальные предметы (ИЗО, музыка и др.) видны серым, не нажимаются.
- Прогресс по каждому ребёнку не ведём.
- Неделю 16–19.11 на сайт не добавляем: период остаётся 20.11–12.12.
- Уроки лежат списком `LESSONS` в начале `index.html`; расписание
  звонков там же в `TIMETABLE`. Пустые поля показываются как
  «пока не заполнено».
- Шаг А (сейчас): отметки и заметки хранятся на устройстве.
- Шаг Б (в работе): общая Google-таблица для отметок и заметок,
  выложить сайт в интернет, ссылки на материалы с диска.
  - Сайт выкладываем на GitHub Pages (аккаунт заводит учитель).
  - Таблица принимает данные через скрипт `tablica-skript.gs`
    (вставляется в таблицу); его ссылка пишется в `SHEET_URL`
    в начале `index.html`. Пустой `SHEET_URL` = только устройство.
  - Отметки и заметки подписываются именем (сайт спрашивает один раз).
  - Адрес таблицы:
    https://docs.google.com/spreadsheets/d/1l3vOpLqY0zpn005HdKdz5hP6J-UPbSSVAiOXPv6PyDg/edit
  - Конспекты, ДЗ и ссылки учитель вносит в лист «Уроки» той же
    таблицы (строка на урок). Заполненная ячейка заменяет то, что
    записано в `LESSONS`; столбцы «Дата» и «Предмет» не менять.
  - После правки `tablica-skript.gs` учитель вставляет его в Apps Script
    и делает новую версию развёртывания (ссылка /exec не меняется).
  - Сайт и ссылка на таблицу открыты всем, у кого есть адрес:
    фамилии детей и личное в заметки не пишем.

## Как посмотреть результат
В интернете: https://anastasiasinegribova07-web.github.io/uroki-3-klass/
(открывается и с телефона). На компьютере: открыть
`Projects/sayt-uroki/index.html` двойным щелчком.
Правки появляются в интернете только после того, как учитель заново
загрузит `index.html` на GitHub (репозиторий `uroki-3-klass`:
Add file → Upload files → Commit changes). Папку `kartinki` загружают
так же: перетащить в окно загрузки всю папку целиком.
